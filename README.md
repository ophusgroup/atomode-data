# atomode-data

Large binary assets for the [atomode](https://github.com/ophusgroup/atomode)
documentation — the self-contained interactive Plotly/Three.js viewers
(rotating 3D structures, relaxation trajectories, g₃ explorers) that are too
large (~1.2 GB) to live in the docs repo itself.

Served as static files via GitHub Pages at
<https://ophusgroup.github.io/atomode-data> and embedded into
[atomode-docs](https://github.com/ophusgroup/atomode-docs) pages with
`{iframe}` directives, e.g.:

```
https://ophusgroup.github.io/atomode-data/trajectories/si_amorphous.html
```

## Layout

```
browse/         interactive structure-database browser
trajectories/   full shell-relaxation trajectory viewers
fire/           FIRE-refinement movies + g3 viewers, by material
mace/           MACE-MP0 refinement movies + g3 viewers, by material
g3/             interactive g3 heatmap explorers
overview/       rotating multi-cell overview grids
g2_compare/     overlaid g(r) comparison viewers
dftb/           DFTB+ refinement figures
```

## Structure-database browser (`browse/`)

<https://ophusgroup.github.io/atomode-data/browse/> — a browser for a large
sample dataset of disordered atomic structures generated with the atomode pipeline. 
Static HTML/JS: the metadata table (`browse/data/dataset.parquet`) is queried
client-side with DuckDB-Wasm; per-structure files (3D `xyzq.gz`, g(r)/ADF
`pdf.json`, ~36 GB) are fetched at runtime from the HuggingFace dataset
[ehrdt/atomode-db](https://huggingface.co/datasets/ehrdt/atomode-db).

## Regenerating

These files are generated by the export helpers in `atomode`
(`Supercell.export_trajectory_html`, `export_g3_html`, `export_overview_html`,
…) and the scripts in the docs pipeline. They are committed here rather than
built in CI because each viewer bakes in its full trajectory.

**Size note:** the committed viewers are compressed for web delivery —
coordinates rounded to 0.001 Å and trajectory frames decimated to every other
step (the final relaxed frame is always kept). This shrank the set from
~1.2 GB to ~270 MB with no visible change. The viewer JavaScript is untouched;
only the embedded `DATA` payload was rewritten.
